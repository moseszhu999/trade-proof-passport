# External RWP adoption contributions

This directory is reserved for append-only, public, fork-originated External Adoption Pilot contributions.

A qualifying contribution must be submitted from an external fork and contain:

```text
<slug>/
├── pilot.json
├── public-projection.json
└── README.md
```

Every committed field must be synthetic, already public, or explicitly authorized for public release. Confidential commercial material does not belong here.

The repository currently makes no claim that an external adoption candidate exists merely because this directory or the contribution gate exists. Internal synthetic tests, forks, page views, stars, pull requests, and merges count as zero external adoption candidates and zero adoption units.

See `docs/guides/rwp-external-adoption-contribution-gate-v0.1.md`.
